# タイトル別メモ

`MKSetup.exe` は実行ファイル名からタイトルを判定し、下記の初期設定で `mkwrap.ini` を作ります
(定義は `src/setup/profiles.h`)。共通の初期割り当ては次のとおりです。

| パッド | キー | 用途 |
|---|---|---|
| 十字キー / 左スティック | カーソルキー | 移動 |
| Back | F2 | クレジット (コイン) |
| Start | F3 | 1P スタート |
| RB | F4 | 2P スタート |

ゲーム側の「操作の設定」でキーを変えた場合は、`mkwrap.ini` の `[Input]` も合わせてください。

## 第1弾 (InstallShield 3 / 6 / Windows Installer)

### リブルラブル (LR1500.EXE)
- 操作: 左レバー (リブル) = D/X/Z/C、右レバー (ラブル) = カーソルキー。
  パッドは左スティック/十字キー = 左レバー、右スティック = 右レバー (ABXY でも右レバー)。
- 速度: 元のフレーム同期処理 (0x4052C0) は、待ち時間を「待つ前の時刻」から計算しているため
  1 フレームおきに待ちが抜け、精度の高いタイマーでは約 95fps で動いてしまいます。
  `[Patch] FrameSync` でこの処理を MKWrap のフレーム待ち (60.606Hz) に置き換えています。
  一時停止もこのフレーム待ちの中で行うため、エミュレーションごと止まります。

- 「ゲームの設定」「操作の設定」: 1.2 で対策 (下の「設定ダイアログが固まる件」を参照)。

### ドラゴンバスター (DB1500.EXE)
- 操作: A = 剣 (X)、B = ファイア (Z)、Y = ジャンプ (↑)。
- 速度: 16ms 間隔 (62.5Hz) → `GameHz=62.5 TargetHz=60.606`。

### 妖怪道中記 (YD1500.EXE)
- 操作: A = ジャンプ (Z)、B = 攻撃 (X)。
- 速度: 17ms 間隔 (約 58.8Hz) → `GameHz=58.824 TargetHz=60.606`。

### 奇々怪界 (KKKAIKAI.exe)
- 操作: A = 御札 (X)、B = 御祓い (Z)、Y = 水晶玉 (X+Z 同時押し)。
- 速度: 17ms 間隔 (約 58.8Hz) → `GameHz=58.824 TargetHz=60`。
- 設定ファイルの場所をレジストリ `SOFTWARE\TAITO\KikiKaikai\InstallDir` から読むため、`[Registry]` で与えます。
- F11 のフルスクリーンは DirectDraw の排他モード (800x600 8bpp) になりますが、MKWrap では擬似フルスクリーンで表示します。

### ディグダグ (digdug.exe) / ニューラリーX (nrallyX.EXE) / パックマン (PacMan.exe)
- 操作: ディグダグ = ポンプ (SPACE)、ニューラリーX = 煙幕 (SPACE)、パックマン = 移動のみ。
- 速度: ディグダグ・パックマンは元から 60.606Hz で動作 (CPU 割り込み回数で確認)。補正なし。
- クレジット/スタートはメニューのショートカット (F2/F3) なので、パッドからはキー入力メッセージとして送ります (`PostKeyMessages=2`)。

### スプラッターハウス (splatter.exe)
- 操作: A = ジャンプ (X)、B = アタック (Z)。
- 速度: 60Hz → `GameHz=60 TargetHz=60.606`。
- F11 などのフルスクリーンは解像度変更 (ChangeDisplaySettings) を使いますが、MKWrap では擬似フルスクリーンにします。

## 第2弾 (InstallShield 3 / 5 / 6)

### レインボーアイランド (Rainbow.exe)
- 操作: 左右移動 = Z/X (ゲーム初期設定)、A = ジャンプ (B キー)、B = 虹 (V キー)。
- 実行ファイルは UPX 系で圧縮されています。MKWrap は GetProcAddress 経由で解決される関数にもフックを掛けるため、そのまま動作します。
- 速度: 補正なし (60fps で描画)。

### 忍者じゃじゃ丸くん (Jajamaru.exe)
- 操作: 移動 = W/A/S/D、A = ジャンプ (K)、B = 手裏剣 (J)。
- 圧縮実行ファイル。速度補正なし。

### 熱血高校ドッジボール部 (DodgeBall.exe)
- ファミコン版と同じ 4 人用の操作体系です。プレイヤー1: 移動 = W/A/S/D、A ボタン = G、B ボタン = F、START = Enter、SELECT = 右 Shift。
- パッド: A = G、B = F、Start = Enter、Back = 右 Shift。
- 圧縮実行ファイル。速度補正なし。

### ぽっぷんぽっぷ (PopnPop.exe)
- DirectInput を使わないため、MKWrap は **ddraw.dll** として配置されます。
- インストーラ (InstallShield 5) はキャビネットに中身を持たず、CD 上の非圧縮ファイルをコピーする方式です。
  MKSetup はキャビネットの目録に従って CD からコピーします。
- 起動時に CD-ROM 上の `PopnMov\popn_op.avi` を探し、BGM も CD から読むため、`[CD] Emulate=1` で
  ゲームフォルダを仮想 CD-ROM ドライブとして見せます。
- 元は全画面専用ですが、`ModeChangeFullscreen=0` で枠付きの窓として表示します (Alt+Enter で擬似フルスクリーンと切り替え)。
- 操作: A = ショット (X)、B = C キー、Start = スタート (Z)。
- 速度: 約 62Hz (16ms) → アーケード (タイトー F3 システム) の 58.97Hz に合わせて `GameHz=62 TargetHz=58.97`。
- オープニングムービーは Cinepak 形式です。Windows 側にコーデックが無い場合はムービーが再生されないことがあります。

## 第3弾 (セガゲーム本舗)

### ガンスターヒーローズ (GUNSTAR.exe)
- 2004 年のメディアカイト「セガゲーム本舗」。中身は Gens 系のメガドライブエミュレータで、ROM が実行ファイルに入っています。
- インストーラは無く、CD の `SEGA-GAMEHOMPO` フォルダから直接起動する形式です (`start.exe` はメニュー画面)。
  MKSetup はこのフォルダを展開先へコピーします。CD が無くても起動します。
- 起動時に画面を 640x480・16 ビットカラーに切り替えて全画面風に表示する作りです。MKWrap では解像度を変えず、
  枠付きの窓で表示します (`ModeChangeFullscreen=0`、Alt+Enter で擬似フルスクリーン)。窓の大きさはマウスで変えられます。
  ゲーム自身も Alt+Enter を全画面切り替えのショートカット (アクセラレータ) に持っていますが、MKWrap 1.3.1 からは
  MKWrap の擬似フルスクリーン切り替えが優先されます。
- 描画は `IDirectDrawSurface::SetSurfaceDesc` でエミュレータの画面バッファ (336x240、16 ビット RGB565) を
  サーフェスの実体にする方式です。MKWrap 1.3 で対応しました。グラフィックメニューの「高画質」も動作します。
- 速度: 垂直同期待ち (`WaitForVerticalBlank`) で 1 フレームずつ進むため、`RefreshRate=59.922` でメガドライブ (NTSC) の周期に合わせています。
- 操作 (キーボード 1P): 方向 = カーソルキー、A = J、B = K、C = L、START = Enter。ESC = ポーズ、TAB = リセット、
  Shift+F5 = ステート保存、Shift+F8 = ステート読込。
- パッド: メガドライブの A/B/C の並びに合わせて X = A (J)、A = B (K)、B = C (L)、Y = A (J)、Start = START、Back = ポーズ (ESC)。
- セーブとステート保存はマイドキュメント\sega\gamehompo\ 以下に作られます。

## 設定ダイアログが固まる・落ちる件 (リブルラブル / ドラゴンバスター / 妖怪道中記)

**原因 (1.2.2 で修正):** 3作は同じ MFC 製のエンジンで、設定ダイアログの `WM_CTLCOLOR` ハンドラが、
既定の色の処理を「窓を持たない CWnd オブジェクト」(ダイアログのメンバー) に転送しています。
その結果 `CWnd::Default()` が `DefWindowProcA(NULL, WM_CTLCOLORDLG / WM_CTLCOLOREDIT, ...)` を呼びます。

- Windows 98～10: 窓ハンドルが無効なので何もせず 0 を返す (問題が表に出ない)
- Windows 11: USER32 内で NULL を参照してアクセス違反 → ダイアログを描く前に落ちる。
  Windows のエラー報告が数秒かかるため、「ダイアログが真っ白で固まり、3～4 秒後に落ちる」ように見えていた

呼び出し元: 妖怪道中記 YD1500.EXE+477b5 / リブルラブル LR1500.EXE+30907 / ドラゴンバスター DB1500.EXE+24aa4
(いずれも MFC の CWnd::Default 内の `DefWindowProcA(m_hWnd, ...)`)。

MKWrap はゲームの `DefWindowProcA` をフックし、窓ハンドルが NULL のときは、WM_CTLCOLOR* なら対象のコントロール (lParam) の窓で既定処理を行い、
それ以外は 0 を返します (`[Patch] FixNullDefWindowProc`)。ラッパー無しで動かす場合も、この3作は Windows 11 では設定ダイアログで落ちます。

設定メニューの処理 (妖怪道中記):
- 「ゲームの設定」(ID 32771) → 0x405ED0: エミュレーションのスレッドを一時停止してから CDialog::DoModal
- 「操作の設定」(ID 32772) → 0x4061E0: 同様に一時停止してから CPropertySheet::DoModal (ボタン 3 つを自前で作成)
- ダイアログ表示中も描画スレッドは画面転送を続けるため、1.2.1 から表示依頼の間隔を空けています。
