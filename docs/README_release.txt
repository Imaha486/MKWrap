MKWrap 1.3.1 ― メディアカイト系 移植ソフト用 展開ツール ＋ 汎用ラッパー
======================================================================

■ 同梱物
  MKSetup.exe   … CD から「展開だけ」を行い、ラッパーと設定ファイルを配置するツール
  dinput.dll    … 汎用ラッパー本体 (MKSetup.exe にも内蔵。手作業で置くとき用。
                   DirectInput を使わないタイトルには ddraw.dll という名前で置きます)
  LICENSE / THIRD_PARTY_NOTICES.md

■ 使い方
  1. MKSetup.exe を起動します。
  2. 「展開元」に CD ドライブ (ISO をマウントしたドライブでも可) か、CD の中身のフォルダを指定します。
     インストーラは実行せず、ファイル一式を「展開先フォルダ」へ展開するだけです。
     レジストリもスタートメニューも変更しません。
     インストーラが見つからないフォルダを指定した場合は、展開済みのゲームフォルダとして
     ラッパーと mkwrap.ini の配置だけを行います。
  3. 「実行」を押し、完了したら展開先のゲーム本体をそのまま起動してください。

  コマンドライン: MKSetup.exe <展開元> <展開先> [/nowrap]
                  MKSetup.exe /wrap <ゲームフォルダ>

■ 対応タイトル (初期設定入り)
  リブルラブル / ドラゴンバスター / 妖怪道中記 / 奇々怪界 / ディグダグ / ニューラリーX /
  パックマン / スプラッターハウス / レインボーアイランド / 忍者じゃじゃ丸くん /
  熱血高校ドッジボール部 / ぽっぷんぽっぷ / ガンスターヒーローズ (セガゲーム本舗)
  それ以外のタイトルも汎用設定で配置します (ボタン割り当ては mkwrap.ini で調整してください)。

■ 主な操作
  Alt+Enter … 擬似フルスクリーン切り替え     Pause キー … 一時停止
  パッド: Back = コイン(F2)、Start = 1P スタート(F3)、RB = 2P スタート(F4)
  (タイトルごとの割り当ては mkwrap.ini の [Input] に書いてあります)

■ 元に戻すには
  ゲームフォルダの dinput.dll (または ddraw.dll) を削除してください。

■ 注意
  ・動作確認は Linux 上の Wine で行っています。実機の Windows 11 と実際の XInput コントローラでは未確認です。
  ・固まった場合はゲームフォルダに mkwrap_hang.log / mkwrap_hang.dmp、
    異常終了した場合は mkwrap_crash.log / mkwrap_crash.dmp が作られます。原因調査に使えます。
  ・ぽっぷんぽっぷは仮想 CD ドライブを使い、枠付きの窓で表示します。オープニングムービー (Cinepak) が再生されない場合があります。
  ・セガゲーム本舗 (ガンスターヒーローズ) はインストーラが無く CD から直接起動する形式のため、
    MKSetup はゲームのフォルダ (SEGA-GAMEHOMPO) をそのまま展開先にコピーします。

詳しい説明・設定項目・ソースコードは GitHub のリポジトリ (README.md と docs/) を参照してください。
